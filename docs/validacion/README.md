# Evidencias de validación con usuarios
Colocar aquí: formularios de consentimiento, capturas/fotos/grabaciones, `resultados.csv` (ID, modalidad, ¿cerró ronda válida?, errores, tiempo por turno, satisfacción 1–5, latencia percibida 1–5, SUS) y notas de observación.
No se incluyen datos inventados: se completan tras las sesiones reales.

El kit para correr una sesión (guion del moderador, hoja de observación, preguntas y consentimiento) está en `sesion.md`. `npm run validacion` (desde `backend/`) resume `resultados.csv`.
