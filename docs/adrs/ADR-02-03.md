# ADR-02/03 Modalidades como plug-ins (Strategy) con registro

**Estado:** Vigente

**Contexto.** Debe poder agregarse una modalidad sin tocar las existentes.

**Decisión.** Interfaz ReglaJuego, un plug-in por modalidad y RegistroReglas; el motor solo conoce el contrato.

**Consecuencias.** Cumple Open/Closed. El contrato debe evolucionar con cuidado.
